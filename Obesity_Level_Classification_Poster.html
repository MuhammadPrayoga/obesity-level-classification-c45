🧠 Penjelasan Algoritma C4.5

Algoritma C4.5 dikembangkan oleh Ross Quinlan sebagai penyempurnaan dari ID3. C4.5 membangun model prediksi berupa pohon keputusan (Decision Tree) dengan langkah:

  • Menghitung Entropy untuk mengukur ketidakpastian data
  • Menghitung Information Gain untuk setiap atribut
  • Memilih atribut dengan Information Gain tertinggi sebagai node
  • Mengulangi proses secara rekursif hingga data terklasifikasi
Rumus Entropy:
Entropy(S) = −Σ pᵢ × log₂(pᵢ)
Rumus Information Gain:
Gain(S, A) = Entropy(S) − Σ (|Sᵥ|/|S|) × Entropy(Sᵥ)

Implementasi menggunakan DecisionTreeClassifier(criterion='entropy') dari library scikit-learn.

📝 Kesimpulan

1. Algoritma C4.5 (Decision Tree) berhasil mengklasifikasikan 7 tingkat obesitas pada dataset Obesity Levels (2087 data setelah cleaning) dengan tingkat akurasi 97.37%.
2. Preprocessing meliputi penghapusan 24 data duplikat, encoding fitur kategorikal (Label Encoding & Ordinal Encoding), dan pembagian data 80:20 dengan stratified sampling.
3. Analisis Feature Importance menunjukkan bahwa Weight (berat badan) adalah fitur paling dominan (58.3%), diikuti Height (20.4%) dan Gender (12.7%), yang mengkonfirmasi bahwa faktor fisik utama sangat berpengaruh terhadap klasifikasi obesitas.
4. Model menunjukkan performa sempurna (100%) pada kelas Insufficient_Weight dan Obesity_Type_III, sementara kelas Overweight_Level_I memiliki recall terendah (90.91%) yang menandakan sedikit kesulitan dalam membedakan level overweight.
5. Algoritma C4.5 terbukti sangat cocok untuk dataset ini karena menghasilkan model yang mudah diinterpretasikan dan memiliki akurasi tinggi.
